# giuliacrippa4.github.io

Personal academic website for Giulia Crippa, served via GitHub Pages at
<https://giuliacrippa4.github.io>.

Plain static HTML/CSS — no build step. To preview locally:

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

## Editing

- Content lives in `index.html`, styles in `style.css`.
- Items marked `<!-- TODO -->` (CV link, LinkedIn URL, Google Scholar) still
  need real URLs.
- Push to `main` and GitHub Pages redeploys automatically.
